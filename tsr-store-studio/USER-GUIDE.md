## 3. ขั้นตอนทำงานจริง (Workflow)

### A. เริ่มโปรเจกต์ใหม่
1. กด **ผังงาน** (มุมขวาบน) → กรอก ชื่อโครงการ / ลูกค้า / สถานที่ / ผู้ติดต่อ
2. เลือก **Phase** (1–7 ตามขั้นตอนขาย–ติดตั้ง)
3. กำหนดขนาดพื้นที่ที่แท็บ **พื้นที่** ของคลังซ้าย (กว้าง × ลึก ซม.) → *ปรับขนาดพื้นที่*
4. เลือกแพ็กเกจ **S / M / L** ที่แผงขวา → กด **ใช้ผังแนะนำของแพ็กเกจนี้**
5. กด **บันทึกผังนี้** เพื่อเก็บเป็น layout ใช้ซ้ำ

### B. วางอุปกรณ์ / ผนัง
1. คลิกจาก **คลังอุปกรณ์** (แท็บ *อุปกรณ์*) → ของจะวางชิดมุมซ้ายบนโดยไม่ทับกัน
2. ย้าย = ลาก · หมุน = ปุ่ม **หมุน 90°** ที่แผงขวา · ลบ = ปุ่ม **ลบ** หรือ `Del`
3. **ปรับขนาด** = เลือกวัตถุ → ลาก **จุดจับมุมสีขาว** (ขนาดจริงแสดงใต้กล่อง)
4. **วาดผนัง** = Ribbon *หน้าแรก* → **วาดผนัง** → ลากบนผัง (กด `F8` เพื่อล็อกฉาก)
5. **วางซ้อนชั้น** = ปุ่ม `L1/L2` ที่ Ribbon (ชั้น 2 แสดง hatch และคิดความสูงซ้อน)

### C. งานระบบ (MEP)
1. Ribbon แท็บ **งานระบบ** หรือคลังแท็บ *งานระบบ*
2. เลือกสัญลักษณ์ → **คลิกในผัง** วางได้หลายจุดต่อเนื่อง (`Esc` เพื่อเลิก)
3. **เส้นท่อ**: เลือก *ท่อน้ำดี* / *ท่อระบายน้ำ* แล้ว **ลาก** เป็นเส้น (หักมุมอัตโนมัติ)
4. ปริมาณไฟ/น้ำถูกถอดเข้า BOQ ทันที และไปปรากฏที่หน้า **งานระบบ & ก่อสร้าง**

### D. ตรวจและออกเอกสาร
1. เปิด **BOQ & ต้นทุน** → ตรวจคอลัมน์ *ที่มาของปริมาณ* (วางในผัง / แบบ MEP / พื้นที่)
2. พิมพ์เลขที่เอกสาร, Rev., วันที่, ผู้จัดทำ/ผู้ตรวจ ในแถบเอกสารควบคุม
3. กด **พิมพ์ BOQ** (3 หน้า + title block) หรือ **พิมพ์สเปค (ลูกค้า)** (ไม่มีตัวเลขต้นทุน)
4. ส่งออกได้: **CSV / Excel** และ *นำเข้า Excel* เพื่ออัปเดตกลับ

### E. เก็บงาน / ส่งต่อ
- **ผังงาน → ส่งออกไฟล์ผัง / คัดลอก JSON** เพื่อส่งให้ทีม
- **นำเข้าไฟล์ผัง** เพื่อโหลดผังของคนอื่นมาเปิดต่อ

## 5. ห้องเซอร์วิส & ผนังอัตโนมัติ

- วาง **ห้องเซอร์วิส** → ระบบสร้าง **ผนังรอบห้องให้ทันที** (เว้นช่องประตูกว้าง 90 ซม. ด้านล่าง)
- ย้าย / ย่อ-ขยาย / หมุนห้อง → **ผนังขยับตาม**
- ลบห้อง → **ผนังถูกลบพร้อมกัน** (ไม่เหลือขยะ)
- ผนังที่ผูกกับห้อง **ไม่ถูกคิดซ้ำ** กับราคาห้อง (ST-005) ในการคิดพื้นที่ผนังเบา

### พื้นยกระดับวางเครื่อง (Platform 40 ซม.)
- อยู่ในคลัง **โครงสร้าง → “พื้นยก +40”** — ลาก **จุดจับมุม** เพื่อขยายให้คลุมเครื่องทุกตัว
- 2D แสดงเป็น **ลายทแยง + ป้าย Y+40** · ไม่นับว่า “ซ้อนทับ” กับเครื่องที่วางบน
- 3D เครื่องที่วางทับจะถูก **ยกขึ้น 40 ซม.** อัตโนมัติ
- BOQ คิดเป็น **ตร.ม. (ST-008)** ไม่ใช่จำนวนชิ้น — ดูที่มาในคอลัมน์ “ที่มาของปริมาณ”

### ขนาดจริง & ระยะห่างขั้นต่ำ
- **อุปกรณ์จริงล็อกขนาดตามสเปกโรงงาน** (เครื่อง / ตู้ / บิ้วอิน / เสา / ประตู / ถัง ฯลฯ) — ปรับขนาดไม่ได้
- **ปรับขนาดได้เฉพาะงานพื้นที่** คือ พื้นยกระดับ และ ห้องเซอร์วิส (โซน)
- **ระยะห่างระหว่างเครื่องต้อง ≥ 10 ซม.** เพื่อการซ่อมบำรุง
  - ถ้าชิดกว่า 10 ซม. จะเห็น **เส้นสีส้ม + ป้าย “ห่าง N ซม.”** ระหว่างเครื่อง
  - status bar ขึ้น ⚠ · มี **toast เตือนทันที** ตอนวาง/ลาก/หมุน
  - ตรวจในแถบ checklist: “ระยะห่างระหว่างเครื่อง ≥ 10 ซม.”

## 7. หน้า งานระบบ & ก่อสร้าง

- **งานไฟฟ้า / งานน้ำ / งานก่อสร้าง** — ตารางแก้ไขได้ทุกช่อง (ตัวเลขที่แก้จะทับค่าที่ถอดจากผัง)
- ปุ่ม **คำนวณอัตโนมัติทั้งหมด** = คืนค่าจากผัง/MEP
- **ตารางโหลดไฟ** และ **ตารางท่อ** — ตรวจ main breaker, สายป้อน, ความยาวท่อ
