ระดับสิทธิ์ (Access levels)

Master Admin
มีได้บัญชีเดียว · ทุกอย่าง + จัดการผู้ใช้ · ลบ/ลดสิทธิ์ไม่ได้
Admin
ดู + แก้ไขข้อมูลทั้งหมด · Export · Settings · ส่ง LINE
Editor
ดู + เพิ่ม/แก้ไข Deal, Project, Ticket, Activity · Export · (ไม่มี Settings)
Viewer
ดูอย่างเดียว · ไม่มีปุ่มแก้ไข/Export
